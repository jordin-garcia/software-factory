# Diseño

- **HTML semántico.** Un solo `h1` por página, encabezados en orden, `button` para acciones y `a` para navegación.
- **Accesible.** Todo se usa con teclado, el foco se ve, cada control tiene nombre accesible y el contraste cumple WCAG AA.
- **Primero el móvil.** La página funciona desde 320 px de ancho sin desplazamiento horizontal.
- **Ligero.** Sin fuentes, imágenes ni scripts de otros dominios. Todo se sirve desde GitHub Pages.
- **Estados completos.** Cada vista contempla el estado vacío, el de carga y el de error, no solo el caso feliz.
- **Textos claros.** Frases cortas, en español, que dicen qué pasa y qué puede hacer la persona.
